# Legacy learning scripts

This folder preserves the earlier exploratory PyTorch exercises separately from
the completed application in `src/`. They are not part of the installed
package or test suite.

The archived scripts cover tensor basics, linear regression, binary and
multiclass toy classifiers, FashionMNIST MLP experiments, and the two EMNIST
models that led to the finished Conv-MLP project.

Downloaded checkpoints, the dataset cache, the Miniconda installer, and a
scraped document export remain intentionally excluded: they are generated,
large, or unrelated to the final source project.
